# SimpleWebHealth

A collection of static healthcare website pages and interface prototypes.

[Repository](https://github.com/MirzaAlbab/SimpleWebHealth)

## Features

- Public home page and spotlight content
- Login and user/doctor registration page layouts
- Administration interface markup

## Technology

HTML, CSS, JavaScript

## Getting started

Clone the repository and serve the root directory with a local static web server. For example, with Python 3:

```bash
git clone https://github.com/MirzaAlbab/SimpleWebHealth.git
cd SimpleWebHealth
```

```bash
python3 -m http.server 8000
```

Open [http://localhost:8000](http://localhost:8000). Keep the relative directory layout intact so styles, scripts, and images resolve correctly.

## Development and checks

Check page navigation, responsive layouts, browser console errors, and missing assets in a browser. No root automated test runner is configured.

## Project structure

- `css/` — Stylesheets
- `html/` — Public page templates
- `img/` — Image assets
- `js/` — Browser scripts

## Project notes

The repository contains frontend pages. Registration and login layouts alone do not establish a working authentication backend.
